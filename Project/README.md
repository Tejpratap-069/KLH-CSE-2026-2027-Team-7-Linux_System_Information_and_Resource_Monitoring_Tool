# Project — Linux System Information and Resource Monitoring Tool

This folder contains the OSSP 25CS2104E project prepared for Team 7.

## Complete source

The complete runnable source package is:

`Linux_System_Information_and_Resource_Monitoring_Tool_SOURCE.zip`

After cloning the repository:

```bash
cd Project
unzip Linux_System_Information_and_Resource_Monitoring_Tool_SOURCE.zip
cd Linux_System_Information_and_Resource_Monitoring_Tool
make
./monitor_web
```

Open `http://localhost:8080`.

The source archive contains the C backend/core, frontend dashboard, documentation, scripts, tests, configuration examples, and Makefile. Compiled object files/binaries are intentionally excluded; run `make` to generate them.
