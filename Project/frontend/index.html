WHY THIS IS OSSP

From user space to kernel data.

The web dashboard is only the presentation layer. The important monitoring core remains C/POSIX and reads real Linux interfaces directly.

C11POSIX socketspthreads/proc/sys
/proc

CPU, memory, uptime, process stat/status, cmdline, I/O, maps and FDs.

/sys

Network interface state and byte counters from the kernel device model.

System calls

open/read/close, sockets, fork, pipe, waitpid and sigaction.

Process management

PID, PPID, states, creation identity, termination and lifecycle tracking.

Memory

Physical RAM, swap, virtual memory, resident memory and process address space.

Concurrency

POSIX collector and HTTP worker threads protected by mutexes.

Signals

Ctrl+C is handled through sigaction() for clean shutdown.

Remote SSH

Agentless, authorized monitoring using controlled fork/exec/pipe of OpenSSH.
